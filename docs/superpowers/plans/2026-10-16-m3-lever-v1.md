# M3 Lever v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One printable throttle lever plus Pico firmware that enumerates as a USB HID joystick and reports lever angle on axis X.

**Architecture:** Parametric OpenSCAD parts sharing one `params.scad`. Quadrant = two cheeks with 608ZZ pockets, joined by two bumper posts (which are also the hard stops) and a bottom bridge that carries a friction shoe pressing on the hub rim. Arm = 16 mm aluminium tube (or 5/8" dowel) clamped into a printed hub and grip. AS5600 reads a magnet in a printed cap on the shaft end. RP2040 Pico firmware (Arduino-Pico core) reads AS5600 over I2C0 and reports HID X.

**Tech Stack:** OpenSCAD 2021+ CLI, Python 3.12 (STL checks), Arduino-Pico core + arduino-cli.

**Spec:** `phaethon.html` §4, §7, §9 (published: https://claude.ai/artifact/VeY5CdSPzxcEq568JgkJh8)

**Status 2026-10-16:** Tasks 1–4 done. Deviations from the plan text below:
- All modules live in `cad/lever_parts.scad`, plus `parts.scad` (export by `-D part=N`) and `assembly.scad`.
- `build.py` replaces `build.ps1`, because PowerShell 5.1 mangles OpenSCAD's quoted `-D` strings.
- The calibration buttons are the two thumbs, GP10 and GP17, not GP10/GP11.
- `boss_d` went from 26 to 30 (flattened to ±14) so the insert wall is 6.9 mm.

Verified: 10 STLs within 220 × 220. Clash free at −1.5°..61.5°, 31.6 mm³ overlap at −4° and 64°. Firmware compiles to a 64 KB UF2. Not verified: printed fit, real sensor jitter, HID axis order on hardware.

## Global Constraints

- 608ZZ bearings (22 OD / 8 ID / 7 W), 8 mm shaft, 60° throw, about 260 mm pivot to grip.
- Every printed part fits a 220 × 220 mm bed. PETG, 4 walls, 35% gyroid.
- Brass heat-set inserts (M3/M4) wherever a screw is removed more than twice.
- AS5600 DIR pin tied to GND. Throttle on I2C0 (GP4/5). Report: X = left throttle, full range idle→max.
- Spec deviation (deliberate): the arm is a 16 mm tube, not a printed arm. Reason: bending strength, bed size, and the wires run inside it.

## Review Focus

1. Lever swing hits a cheek or spacer before the bumper stop → assembly check at −2° and 62° must show zero overlap between moving and fixed parts.
2. Steel shaft distorts the magnet field → magnet sits in a printed cap ≥ 4 mm proud of the shaft end; recommend A2 stainless or aluminium shaft.
3. Lever flops forward under its own weight → friction shoe on the hub rim, adjustable with an M5 thumbscrew.
4. AS5600 angle wraps through 0/4095 mid-throw → firmware unwraps relative to a calibrated idle angle before scaling.
5. Bearing pocket prints undersize and the bearing won't seat → pocket diameter is a parameter (default 22.15) with a printed test coupon.

### Task 1: Shared parameters and quadrant cheeks

**Files:**
- Create: `cad/params.scad`, `cad/cheek.scad`
- Test: `cad/check.py`

**Interfaces:**
- Produces: `params.scad` constants used by every part: `pivot_h=70`, `gap=31`, `hub_w=28`, `rim_r=22`, `brg_od=22.15`, `brg_w=7`, `shaft_d=8`, `tube_d=16.3`, `throw=60`, `stop_margin=2`. `check.py <stl> [--bed 220]` prints the bounding box and exits 1 if X or Y exceeds the bed.

- [ ] Write `check.py` (ASCII and binary STL bbox, bed check, triangle count > 0).
- [ ] Model `cheek(side)` with a bearing pocket on the inner face, a Ø16 lip hole, a foot with 2× M5, holes for 2 bumper posts, and bridge bolt holes.
- [ ] Render `cheek_L.stl`, `cheek_R.stl`; `check.py` passes the bed check.

### Task 2: Hub, bumper posts, bridge and friction shoe

**Files:**
- Create: `cad/hub.scad`, `cad/bridge.scad`, `cad/assembly.scad`

**Interfaces:**
- Consumes: `params.scad`.
- Produces: `assembly.scad` with `lever_angle` (degrees, 0 = idle) and `part=` selector for `moving` or `fixed` sub-assemblies.

- [ ] Hub: shaft bore with an M4 pinch clamp, round rim `rim_r`, radial tube socket (depth 35) with an M4 pinch.
- [ ] Bumper posts placed so the socket boss touches them at −2° and 62°.
- [ ] Bridge between the cheeks under the hub with an M5 thumbscrew nut trap and a shoe.
- [ ] Interference test: `intersection(){moving(a); fixed();}` renders empty at a = 0, 30, 58; at a = −2 and 62 the socket boss touches the posts (overlap volume < 1 mm³).

### Task 3: Magnet cap, sensor bracket, grip

### Task 4: Pico firmware

**Files:**
- Create: `firmware/phaethon_levers/phaethon_levers.ino`, `firmware/README.md`

- [ ] Read AS5600 RAW ANGLE (reg 0x0C/0x0D) on Wire (GP4/5) at 400 kHz, 4× oversample.
- [ ] Unwrap relative to the idle angle stored in flash, then scale idle→max to the full HID axis.
- [ ] Calibrate: hold both thumb buttons (GP10, GP11) for 3 s, sweep the lever, release → save min/max to EEPROM emulation.
- [ ] Compile with arduino-cli for `rp2040:rp2040:rpipico` with USB stack `tinyusb`; zero errors.
