REPRODUCTION
Godot 4.7.1 stable, matching official Windows x64 release template.
tools/run_godot.py wraps bounded import/export/editor checks.
tools/package_release.py assembles the explicit distribution allowlist.
tools/run_export.py wraps bounded actual-player runs.
Player user arguments: --verify-release --evidence=<absolute directory>
Use engine flags --audio-driver Dummy --max-fps 60 before the separating --.
The diagnostic is opt-in; ordinary launch opens the player menu.
For PC VR use tools/package_release.py --edition pcvr. Its diagnostic arguments:
--xr-mode off --audio-driver Dummy --max-fps 60 -- --verify-vr-release
--verify-xr-off --evidence=<absolute directory>. This checks scene construction
outside the headset; the separate live-headset tests establish hardware use.
Normal PhaethonVR.exe startup requires an initialized OpenXR session and opens
the native cockpit. The PC VR diagnostic cannot run in a live headset session.
