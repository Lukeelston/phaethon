VERSION 0.1.1 TUNING UPDATE - 2026-11-02
The v0.1.0 publication record above remains historical. The following records
the local successor build, not a claim that Stan has been updated.

Five trigger-control gears replace four. Each successive gear winds up more
slowly to a higher engine note. At normal full trigger the V8 audio ceilings
are approximately 4,870 / 5,540 / 6,210 / 6,880 / 7,550 RPM; time to 90% of each
audio target is 0.975 / 1.650 / 2.650 / 4.233 / 6.875 seconds. Every upshift
still drops both engine voices. Desktop without a gearbox retains its prior
rev response. Fifth alone enables afterburner and overdrive.

Fifth has no programmed speed limiter. Baseline aerodynamic drag approaches
nominal full-throttle thrust exponentially, producing logarithmic speed growth.
Air-brake drag remains unchanged. Releasing the triggers, partial throttle,
or failed engines still slow the craft. Both handling modes and boost states
were exercised in the real simulation. Overdrive is scoped to geared trigger
controls, so legacy desktop and other VR control schemes keep their drive model.

Five-second speed gains starting at 2,000 / 4,000 / 6,000 m/s were respectively
231.843 / 52.937 / 11.444 m/s. A two-minute straight run starting at 2,000 m/s
reached 3,006.621 / 3,565.599 / 3,954.545 / 4,253.125 m/s at 30-second intervals.
The long-run test translates the rigid bodies back along the finite range
without altering velocity, so it tests drive behavior without hitting the

SPEED SHIELD
The original field was a 120 Hz buzz with a startup pitch sweep and only a 4%
airspeed pitch change. It now has a fixed 36 Hz low layer (supporting harmonics
at 72/108/144 Hz), reverberating on FieldRumble, and a separate dry speed tone
feeding Field. Keeping reverb off that second voice removed a captured octave
jump caused by an overtone becoming dominant. The broad spectral check was
retained, not narrowed to hide the jump.

Captured strongest speed-tone peaks: 180 / 297 / 414 / 531 Hz at respectively
1,500 / 3,000 / 6,000 / 12,000 mph; bass peak remained 36 Hz at all four speeds.
Field RMS -23.0 dBFS. After stopping the sources, the reverb tail declined from
-27.6 to -40.6 dBFS over roughly 0.6 seconds. Shield tests 29/29 passed; an
independent run passed all 28 checks without the optional capture-save check.
RPM/gear/throttle independence, actual deceleration, 1,500/1,300 mph hysteresis,
seal timing, wind muffling, source release and effect reuse were verified.
The existing wind-audio capture passed unchanged, with 15 ObjectDB cleanup
warnings at exit. The new shield test completed without errors or warnings.
Read-only review found no remaining material defects. These are captured-audio
results; headset listening and the new mix's subjective balance need confirmation.

VERSION 0.1.2 - FIFTH-GEAR ENGINE NOTE
Luke's subsequent headset feedback identified a real defect in v0.1.1: fifth
kept accelerating but its engine note plateaued. The earlier audio test ended
at the reference redline and did not exercise this path beyond it.

Fixed the three-layer rev clamp: fifth's gearbox revs now continue as 1+log(x)
above reference speed x=1; the view passes separate uncapped audio spool targets;
EngineAudio accepts those targets only for fifth overdrive and removes its 16x
playback clamp for the four tonal engine layers in that case. Normalized gain
and load inputs remain bounded. Repair, lift, downshift, boost, and flameout
responses remain active. Physics and the speed-shield implementation are unchanged.

Extended anti-alias sample levels to 64x playback for V8/V12, 16x for the second
engine, and 20x for the turbine. These are filter-design ranges, not playback
limits. Refiltered the previous final levels too, so they remain safe throughout
their fade into new levels. The generator measures correlated mixed transitions;
worst energy above the 20 kHz playback margin was 1.15e-8 of total. Nine new WAVs
are included, with updated attribution. Eight early levels remain byte-identical.
All 33 WAV imports are PCM16; actual loaded tonal resources were checked for
mono format, forward looping, and identical frame lengths within each layer.

Verification: initial regression reproduced the plateau; final behavioral checks
32/32 passed in both handling modes, plus 17 final capture/import checks. Ten
fresh solo V8/V12 recordings passed actual PCM pitch analysis with ~0.01% error.
At 1.2 / 2 / 3 / 4 / 8 times reference speed, captured V8 notes were respectively
584.8 / 813.0 / 994.1 / 1122.6 / 1432.3 Hz; V12 notes were
1365.8 / 1908.4 / 2339.1 / 2644.6 / 3380.8 Hz. No plateau or clipping occurred.
Equal-speed pitch increments decrease. The new test also verifies lower-gear
ceilings, throttle lift, downshift, repair, flameout/relight, burner and ramjet.
Existing gear-audio checks 34/34 and gear/control checks 12/12 passed.
Legacy engine capture: 26/26 PCM16 loops, 30.5 seconds, peak -1.0 dBFS,
RMS -15.8 dBFS, no clipping. The legacy harness logged 107 ObjectDB cleanup
warnings; the new capture harness logged 78. Behavioral checks exited cleanly.
Independent review found no remaining material defects after the filter and
