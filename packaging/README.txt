PHAETHON
Experimental Desktop Racer - Windows x64 - v0.1.1
ElstonWorks

Two engines. One cockpit. We know it's a little fucky.

GET IN
1. Extract the whole ZIP into a folder.
2. Keep Phaethon.exe and Phaethon.pck together.
3. Double-click Phaethon.exe. Choose the 100-mile sprint first.
No Godot editor, account, headset, or online connection is required to play.

WHAT YOU BOUGHT
An offline, single-player physics experiment with three courses:
- 100-mile sprint: build speed, survive, then stop in the finish box.
- Grand Prix: a circuit with tighter Starfighter handling.
- Eridanus: a long course to explore and push your luck on.
You steer using the difference between your left and right engine thrust.
This is a small experimental build, not a finished campaign. Expect strange
handling, sparse scenery, rough collisions, and the occasional spectacular
mistake. There is no multiplayer. This download is the flat-screen edition.
Future features, updates, and other platforms are not part of this purchase.

FIRST FLIGHT
Hold E briefly to raise both throttles, then release it. Throttle stays where
you leave it. Hold D to reduce both; X cuts both. Engine thrust does not brake
you: hold A and Right Arrow together for both air brakes. Brake early.
Use unequal thrust or individual air brakes to turn. Small inputs are useful.
Backspace returns you to the track but keeps the throttle setting. Cut with X
first, or use Escape > Restart course for a completely fresh start.

KEYBOARD
E / D              Both throttles up / down
W / S              Left throttle up / down
Up / Down          Right throttle up / down
A / Right          Left / right air brake (hold both to brake straight)
X                  Cut both throttles
Space              Reignite engines
H                  Hold to repair
R                  Arm ramjet
M                  Switch handling mode
Backspace          Reset to track (keeps throttle)
Escape             Pause / resume; restart, menu and quit are available here

CONTROLLERS
Keyboard is the supported starting point. Gamepad support is experimental:
left and right stick forward control the matching engines; triggers brake.
A reignites, X repairs, Y arms the ramjet, Back resets. Keyboard controls take
priority until you return the sticks/triggers to neutral. Physical controller
compatibility has not been verified for this build. Printed lever hardware is
not included and is not required.

SYSTEM AND KNOWN LIMITS
Windows x64 desktop with a Vulkan-capable graphics driver. The release was
render-tested on Windows with an NVIDIA GeForce RTX 5080 at 1280 x 720.
Minimum GPU and performance on other machines have not been established.
Mac, Linux, mobile, standalone Quest and VR are not supported by this package.
The executable is unsigned. Download it from the ElstonWorks product page.
The window can be resized; Escape provides controls if you get lost.

Local game data is stored under the Windows application-data directory:
ElstonWorks/Phaethon. The game has no online account or telemetry integration.
